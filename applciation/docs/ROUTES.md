# API route index

Generated by `npm run docs:routes` from the route files (679 endpoints). Do not edit by hand.

- **Who** is the role allowed to call it. "any staff" means any signed-in staff member; department coordinators only ever see their own department's students.
- **Module** is the paid module that must be enabled for the college; blank means core.
- **Limit** is the per-user rate limit (requests per window) where one is set.
- Every response is JSON `{ "data": ... }` or `{ "error": { "code", "message", "details?", "requestId" } }`, except file downloads (Excel / PDF).
- Send `Authorization: Bearer <Supabase access token>`. Lists use `?limit=&cursor=` and return `{ items, nextCursor }`.
